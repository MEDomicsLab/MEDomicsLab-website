## Description

Stereotactic radiosurgery (SRS) can cause adverse radiation effects (ARE) that are difficult to distinguish from tumor progression, even though the two events require completely different therapeutic approaches. It is therefore particularly relevant to identify the patients at high risk of developing ARE. This project aims to build a simple and predictive radiomic model for ARE.

To do so, image features from the brain magnetic resonance imaging (MRI) acquired before SRS treatment, as well as features from the dosimetry maps, will be extracted with [MEDiml](/research/mediml), a software for radiomic computation and machine learning that follows the guidelines of the Image Biomarker Standardisation Initiative (IBSI). The features will then be reduced by identifying the [optimal levels of radiomic complexity](/research/radiomics-complexity), and the best-performing and simplest model will be retained.

This project will help demonstrate that radiological images could be used to quantify risks in a non-invasive and personalized way.
